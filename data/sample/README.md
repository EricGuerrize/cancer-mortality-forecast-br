# Amostras (sem microdados reais)

- `cancer_deaths_agg.parquet`: contagens por UF × sexo × faixa etária × grupo de câncer × ano, com células < 5 suprimidas.
- `ill_defined_counts.parquet`: contagens de causas R00–R99.
- `ibge_population_sample.parquet`: recorte sintético de população.
- `cancer_deaths_micro_mock.parquet`: microdados **sintéticos** para testes (não são registros do SIM).

Nenhum arquivo aqui contém PII ou microdados reais do DATASUS.
